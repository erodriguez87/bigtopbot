# BigTopBot

BigTopBot is a consumer robotics news and product comparison platform. Built with Next.js and Tailwind CSS, it features a custom dark-mode aesthetic, dynamic hardware indexing, and side-by-side specification comparisons for autonomous lawn mowers and robot vacuums.

## Features
* **Dynamic Hardware Index**: Filter consumer robotics by category (Mower, Vacuum) and price parameters.
* **Matrix Comparison Tool**: Side-by-side specification breakdowns for mechanical tolerances, navigation systems, and capabilities.
* **Latest Intelligence Feed**: Up-to-date robotics industry news and hardware release updates.
* **Responsive Dark-Mode UI**: Built with Tailwind CSS utilizing glassmorphism effects and cyan accents.

## Tech Stack
* **Framework**: Next.js 14 (App Router)
* **Library**: React 18
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **Deployment**: Vercel

## Getting Started
Clone the repository and install the required dependencies:
```bash
git clone https://github.com/erodriguez87/bigtopbot.git
cd bigtopbot
npm install
```
